# Plantillas JSON LMS

Las subcarpetas AVSEC, MERCANCIAS_PELIGROSAS y SMS contienen una instancia estructural de cada contrato descrito en `03_MODELO_DATOS/MODELO_JSON_MAESTRO.md`.

Los valores `TEMPLATE`, campos vacíos y marcadores entre `< >` son intencionales: estos archivos no son contenido publicado ni importable. No se asignaron identificadores de negocio nuevos. AVSEC conserva únicamente los códigos existentes en el catálogo demo. Antes de importar, completar y validar todas las referencias, versiones, contenido, derechos y aprobaciones editoriales.

El banco y la configuración de examen están vacíos. Las preguntas genéricas del reproductor de Fase 7 son datos de prueba separados, no pertenecen a estas plantillas y no deben reutilizarse en capacitación.
