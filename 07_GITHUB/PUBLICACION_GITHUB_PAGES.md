# Publicación en GitHub Pages

## Checklist previo a publicación

- [ ] Confirmar el repositorio, la rama y el origen autorizados.
- [ ] Preparar una distribución independiente y plana en la raíz publicada.
- [ ] Colocar en esa raíz los archivos y recursos que la publicación necesite.
- [ ] Verificar rutas, enlaces, mayúsculas/minúsculas y carga de recursos.
- [ ] Probar la experiencia responsive en móvil, tableta y escritorio.
- [ ] Revisar accesibilidad, navegación, formularios y estados de error.
- [ ] Confirmar que no haya secretos, credenciales ni datos personales.
- [ ] Validar la distribución en el contexto de rutas de Pages.
- [ ] Registrar navegadores, resoluciones, resultados y limitaciones.
- [ ] Obtener autorización antes de publicar o desplegar.
